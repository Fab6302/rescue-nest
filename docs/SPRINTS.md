# RescueNest sprint records

## Sprint 0 · Preparation

Deliverables include Laravel setup with Composer lockfile, a MySQL configuration, database migration, shared Blade layout, the project SRS, and the class diagram. The quick-start launcher uses a separate SQLite demo configuration. GitHub repository creation and collaborator invitations are team tasks.

## Sprint 1 · Accounts and community

| Brief item | Where to demonstrate |
| --- | --- |
| Accounts | Register, log in, remember me, log out, reset password, and edit account |
| 1 Pet profiles | Pets → Add pet profile → Edit |
| 2 Pet discovery | Pets → filter by breed, animal type, and area |
| 3 Updates | Your pet → Share an update → edit or remove your post |
| 4 Comments and replies | Community update → Add a comment → open the comment to reply |
| 5 Saved items | Open an update, adoption post, or shop → Save → Saved |

## Remaining brief sprints included in the build

| Brief item | Where to demonstrate |
| --- | --- |
| 6–7 Adoption management and search | Adoption → Add adoption listing, edit, withdraw, and browse with filters |
| 8–10 Requests, decisions, handover | Another member requests adoption → owner opens the request to ask a question, decide, or confirm handover |
| 11–12 Shop and product management | Shop account → Add shop profile → Add a product or edit its listing |
| 13–14 Shop and product search | Shops and Products screens |
| 15 Reviews | Open a shop → write, edit, or remove your review |
| 16–18 Lost and found | Lost & found → report, edit, resolve, and filter notices |
| 19 Sightings | Another member opens an open lost notice and reports a sighting → owner opens the sighting to review or ask for clarification |
| 20 Moderation | Report a public item → moderator opens Moderation to dismiss or remove the content |

The original SRS records the proposed team workload and faculty approval requirements. AI generated the implementation and the initial verification material. Team members should review the source, run their own acceptance checks, and record their own contributions before submission.
